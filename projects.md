Several group project are planned to occur over the workshop. These mostly concern the re-analysis of previously published data, but applying techniques and concepts covered throughout the workshop.

## Project 1 - *Varecia variegata*

The effect of landscape features on the genetic diversity and differentiation of Varecia variegata has been studied at several scales using resistanceGA. This project aims to revisit these effects using new modeling and surface optimization approaches, as well as including new/other/additional landscape variables.<br>

**Data:** microsatellite data to be shared by Andrea Baden (she is preparing it).<br>
